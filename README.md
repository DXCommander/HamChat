# HamChat

**HamChat** is a no-setup, LAN-based sticky-note-style chat application for quick internal messaging.  
Runs with no server, no config — just fire up and chat!

---

## 💡 Features

- Auto LAN discovery (no setup)
- Change name (Station 1 → BigJon etc)
- Timestamped messages
- Pale-yellow post-it style interface
- Flashes on new message
- Italics for your own outgoing messages
- Right-click: Change name, Show users, Enable test mode
- “Test Mode” lets you run multiple clients on the same PC

---

1. Install Python 3.10+ (if not already)
2. Run from source:
